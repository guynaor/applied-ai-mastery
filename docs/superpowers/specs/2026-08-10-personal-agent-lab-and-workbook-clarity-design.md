# Personal Agent Lab and Workbook Clarity Design

## Purpose

Extend the Personal Course so that unattended agents are taught as a bounded, observable practice rather than only discussed abstractly. Make every workbook task legible as a concrete homework sequence.

## Learning path

Session 2 adds an optional Unattended Agent Lab after the purchase-research workflow:

1. Everyone designs and evaluates an agent without installing software.
2. The facilitator can demonstrate a full OpenClaw installation connected to a paid cloud/API model and a public-data shopping monitor.
3. Students with suitable devices can follow a minimal local OpenClaw plus Ollama route using only local/public inputs and manual test runs before scheduling.
4. An Advanced Adventure track supports a student-owned cloud/provider setup, with budget controls and no external action beyond an alert/draft.

The shopping monitor may alert on a meaningful price/availability change. It may not buy, submit payment, contact sellers, access financial accounts, trade, or offer personalised investment advice. The Session 7 portfolio changes from paper-only discussion to reviewing evidence from a bounded agent operation.

## Materials

- English and Hebrew Session 2 student pages explain the common no-install activity, local lab, and advanced track.
- English and Hebrew Session 2 facilitator guides provide a complete instructor cloud-demo runbook, safe example prompts/configuration concepts, setup checks, a run script, troubleshooting, and a stop procedure.
- AI geography documents distinguish local and cloud agent runtimes and point to the course route.
- Both learning journals include a Session 2 agent-run record and replace ambiguous homework wording with a repeatable Goal → Steps → Bronze/Silver/Gold block in every session.
- Workbook generator and content tests preserve the requirements in downloadable DOCX files.

## Safety and accessibility

Installation is optional. The no-install route creates the same core artifact: an agent specification, test case, and run-review record. Local-model learners are warned about device capacity and reliability. Paid API credentials belong only to the account owner; no learner shares keys. All agent activities use public or mock data and retain human approval boundaries.

## Verification

Automated content checks assert that both journals contain homework Goal/Steps/level structure, that Session 2 includes the three learning routes, and that the former paper-only restriction is removed consistently. The DOCX build and inspection checks confirm the content ships in both downloadable workbooks and Hebrew remains RTL.
