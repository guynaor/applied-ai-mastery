# Hebrew Teacher Course Audience Copy Design

## Goal

Simplify Hebrew Teacher-track audience and capstone copy without changing the instructional grade-band examples inside mission materials.

## Copy rules

- Broad Hebrew course and portal audience references use **א׳–י״ב**.
- The Hebrew capstone title uses exactly: **יחידת לימוד ליסודי, לחטיבה או לתיכון בבדיקת מורה**.
- Hebrew mission materials may retain the three detailed Israeli school bands only where an activity explicitly teaches differentiated pedagogy.
- English K–12 copy and non-Hebrew artifacts remain unchanged.

## Validation

Extend the Teacher contract to require the exact Hebrew capstone title and prevent the former long capstone phrase from returning. Run the existing Teacher and localization validation scripts after the copy change.
