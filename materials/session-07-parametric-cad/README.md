# Session 7 — Parametric CAD with AI

## Mission

Design a parametric wall bracket for the AquaNode Mini prototype using OpenSCAD and an AI coding assistant. The bracket must be measurable, printable, and easy to revise without rewriting the model.

## Teaching sequence

1. Identify reference surfaces and interfaces.
2. Complete the design contract before generating geometry.
3. Build the simplest valid model first.
4. Test normal and extreme parameter values.
5. Record render, dimensional, fit, and print-orientation evidence.
6. Treat the result as a prototype, not structural certification.
