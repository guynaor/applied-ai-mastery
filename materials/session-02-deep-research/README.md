# Session 2 — Deep Research & Information Synthesis

## AquaForge mission

AquaForge is evaluating whether the next revision of the `AquaNode Sensor Hub` should use a welded structural-steel frame or a modular 4040 aluminium T-slot frame for its vibration-test stand.

The student acts as an **AI Research Analyst** and must produce a decision-oriented memorandum rather than a collection of summaries.

## Learning objectives

The student should be able to:

1. Turn a broad topic into a decision question with explicit constraints.
2. Separate claims, evidence, assumptions, and recommendations.
3. Detect when multiple documents repeat the same underlying source.
4. Identify disagreement caused by incompatible test conditions.
5. Produce a recommendation that includes uncertainty and a next validation step.

## Suggested sequence

1. Read `student/AF-RD-201-decision-brief.md`.
2. Review the four documents in `sources/`.
3. Complete `student/AF-RD-202-evidence-matrix.csv`.
4. Draft the memorandum with `student/AF-RD-203-research-memo-template.md`.
5. Compare the work with `instructor/AF-TRN-201-answer-key.md`.
6. Assess the submission with `instructor/AF-TRN-202-rubric.csv`.

## Instructional design

The source pack is intentionally imperfect:

- Some documents describe different frame geometries and therefore cannot be compared directly.
- One supplier document repeats a manufacturer claim without independent testing.
- One internal test is useful but too small to support a universal conclusion.
- Cost figures use different inclusions.

A strong student should expose these limitations instead of forcing a false numerical winner.
