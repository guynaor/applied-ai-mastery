# Session 5 — Operations Planning

## Mission

Plan a four-day AquaForge field visit in Cyprus for a small technical team. The itinerary must satisfy fixed meetings, cluster optional activities geographically, include realistic transition buffers, and expose every fact that still needs live verification.

## Learning goals

The student should be able to:

1. Separate hard constraints from preferences.
2. Build geographic clusters before assigning times.
3. Distinguish travel time from meeting duration and preparation time.
4. Design alternatives for delays, closures, weather, and fatigue.
5. Export a calendar-ready schedule without hiding uncertainty.

## Suggested teaching sequence

1. Ask the student to mark every hard constraint before planning routes.
2. Create location clusters without times.
3. Add meetings and travel buffers.
4. Stress-test the plan against one delayed flight and one unavailable site.
5. Export the final schedule and inspect it in calendar view.

All locations and travel times in this exercise are fictional. Students must not present them as current real-world facts.
