# Session 4 — Technical Communication and Artifacts

## Mission

AquaForge is preparing an internal approval presentation for a limited AquaNode Mini pilot. The student must turn mixed-quality source material into a concise six-slide decision deck without inventing evidence.

## Learning objectives

The student will:

1. Define audience, decision, and evidence boundaries before designing slides.
2. Build a narrative with one takeaway per slide.
3. Separate supported claims from assumptions and open questions.
4. Specify visuals by explanatory purpose rather than decoration.
5. Critique an AI-generated presentation for repetition, unsupported claims, and weak transitions.

## Teaching sequence

1. Ask the student to state the requested decision in one sentence.
2. Review the source notes and label facts, assumptions, and missing evidence.
3. Draft only slide titles and takeaway sentences.
4. Add evidence and visual briefs after the narrative works.
5. Generate or build a deck, then run the critique checklist.
6. Revise one weak slide and explain why the revision is better.
