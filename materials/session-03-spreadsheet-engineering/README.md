# Session 3 — Non-Coder Spreadsheet Engineering

## AquaForge mission

Operations has exported an inventory table from several systems. The file contains duplicate SKUs, inconsistent dates, mixed units, malformed quantities, missing reorder levels, and conflicting supplier names.

The student must:

1. Define a data contract before cleaning.
2. Diagnose the deliberately messy source file.
3. Produce a clean inventory table without silently inventing missing values.
4. Build a dynamic low-stock summary.
5. Specify and test a safe Apps Script alert workflow.
6. Explain every formula or script in plain language.

## Important instructional rule

The clean reference table is an instructor aid, not an excuse to fill gaps. Values that cannot be supported by the source must remain blank or be explicitly flagged for confirmation.
