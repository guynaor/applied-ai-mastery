# מפגש 1 — פרומפטים מתקדמים ובחירת מודל

## המשימה

צוות ההנדסה של AquaForge קיבל דוח תקלה חלקי על מכלול משאבת נוזל הקירור HydroSense HX-200. על התלמיד או התלמידה להשתמש באותו חומר מקור ובאותו פרומפט מובנה בכמה מערכות AI, ואז להשוות את התוצאות באופן אובייקטיבי.

## תוצרי למידה

בסיום החומר, הלומדים אמורים להיות מסוגלים:

1. להבחין בין LLM, אפליקציית AI, תוצר (artifact), מיומנות (skill) וסוכן (agent).
2. לבנות פרומפט בעזרת מסגרת RISEN.
3. להפריד בין עובדות שסופקו במקור לבין הנחות של המודל.
4. להשוות תוצרי AI בעזרת קריטריונים עקביים.
5. לשנות פרומפט לאחר זיהוי כשל מסוים.
6. לשמור דפוס פרומפט לשימוש חוזר בעבודה טכנית עתידית.

## שימוש מומלץ

1. תנו לתלמיד או לתלמידה רק את הקבצים שמופיעים בקבוצת חומרי התלמיד באתר.
2. הריצו את אותו פרומפט ואת אותו מזכר מקור בשני כלי AI עדכניים לפחות.
3. דרשו דוגמאות מדויקות לכל טענת השוואה.
4. בדקו את העבודה בעזרת מפתח התשובות והמחוון.

## מגבלה חשובה

מזכר המקור אינו מכיל בכוונה די ראיות לאבחון מוחלט של שורש התקלה. תשובת AI חזקה צריכה לזהות את המגבלה הזו ולא להמציא מדידות חסרות.
