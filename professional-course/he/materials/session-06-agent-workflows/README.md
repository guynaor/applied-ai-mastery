# מפגש 6 — תהליכי סוכנים וניטור בטוח

## משימת AquaForge

Priya Nair מבקשת מהתלמיד לתכנן סוכן ניטור תחום עבור עדכוני מצב של ספקים שמשפיעים על פיילוט AquaNode Mini. הסוכן חייב לזהות שינויים משמעותיים, למנוע התרעות כפולות, לשמר ראיות, לחשוף כשלים ולהשאיר החלטות רכש לאדם.

## מטרות למידה

התלמיד:

1. ימדל סוכן כ-Trigger → Action → Decision → Record → Notification.
2. יהפוך בקשת ניטור עמומה למפרט שניתן לבדיקה.
3. יפריד בין מצב נוכחי, היסטוריה שאינה ניתנת לשינוי ומצב התרעה פעיל.
4. יתכנן מניעת כפילויות, התאוששות, ניסיון חוזר וטיפול בנתונים מיושנים.
5. ידגים את התהליך בבטחה באמצעות תצלומי המצב שסופקו ולא באמצעות אתר מסחרי חי.

## רצף הוראה מוצע

1. ציירו את לולאת הסוכן בת חמשת השלבים.
2. בקשו מהתלמיד לזהות פעולות בלתי הפיכות ולהוציא אותן מההיקף.
3. הגדירו שינוי משמעותי לפני המימוש.
4. הפעילו מחדש את תצלומי המצב שסופקו לפי סדר חותמות הזמן.
5. בדקו התרעות צפויות, כפילויות שנמנעו, התאוששות וכשלים.
6. בדקו יומנים לפני דיון בתזמון.
