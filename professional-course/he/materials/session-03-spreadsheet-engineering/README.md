# מפגש 3 — הנדסת גיליונות נתונים ללא תכנות

## משימת AquaForge

מחלקת התפעול ייצאה טבלת מלאי מכמה מערכות. הקובץ מכיל מזהי SKU כפולים, תאריכים שאינם עקביים, יחידות מעורבות, כמויות בפורמט לא תקין, רמות הזמנה מחדש חסרות ושמות ספקים סותרים.

על התלמיד:

1. להגדיר חוזה נתונים לפני הניקוי.
2. לאבחן את קובץ המקור ששובש בכוונה.
3. להפיק טבלת מלאי נקייה בלי להמציא בשקט ערכים חסרים.
4. לבנות סיכום דינמי של מלאי נמוך.
5. להגדיר ולבדוק תהליך התרעה בטוח ב-Apps Script.
6. להסביר כל נוסחה או סקריפט בשפה פשוטה.
