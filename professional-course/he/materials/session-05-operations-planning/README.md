# מפגש 5 — תכנון תפעולי

## המשימה

תכננו ביקור שטח בן ארבעה ימים בקפריסין עבור צוות טכני קטן של AquaForge. המסלול חייב לעמוד בפגישות קבועות, לקבץ פעילויות אופציונליות לפי אזור גאוגרפי, לכלול מרווחי מעבר מציאותיים ולחשוף כל עובדה שעדיין מחייבת אימות בזמן אמת.

## מטרות למידה

התלמיד אמור להיות מסוגל:

1. להפריד בין אילוצים קשיחים להעדפות.
2. לבנות אשכולות גאוגרפיים לפני הקצאת זמנים.
3. להבחין בין זמן נסיעה, משך פגישה וזמן הכנה.
4. לתכנן חלופות לעיכובים, סגירות, מזג אוויר ועייפות.
5. לייצא לוח זמנים מוכן ליומן בלי להסתיר אי-ודאות.

## רצף הוראה מוצע

1. בקשו מהתלמיד לסמן כל אילוץ קשיח לפני תכנון מסלולים.
2. צרו אשכולות מיקום ללא זמנים.
3. הוסיפו פגישות ומרווחי נסיעה.
4. בדקו את התוכנית מול טיסה שמתעכבת ואתר שאינו זמין.
5. ייצאו את לוח הזמנים הסופי ובדקו אותו בתצוגת יומן.

כל המיקומים וזמני הנסיעה בתרגיל זה בדויים. אסור לתלמידים להציג אותם כעובדות עדכניות מהעולם האמיתי.
