## רצף ההוראה

1. זהו משטחי ייחוס וממשקים.
2. השלימו את חוזה התכנון לפני יצירת גאומטריה.
3. בנו תחילה את המודל התקין הפשוט ביותר.
4. בדקו ערכי פרמטר רגילים וקיצוניים.
5. תעדו ראיות render, מידות, התאמה וכיוון הדפסה.
6. התייחסו לתוצאה כאב-טיפוס ולא כהסמכה מבנית.
