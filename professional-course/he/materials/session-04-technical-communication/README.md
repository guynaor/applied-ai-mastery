# מפגש 4 — תקשורת טכנית ותוצרים

## המשימה

AquaForge מכינה מצגת פנימית לאישור פיילוט מוגבל של AquaNode Mini. על התלמיד להפוך חומרי מקור באיכות מעורבת למצגת החלטה תמציתית בת שישה שקפים בלי להמציא ראיות.

## מטרות למידה

התלמיד:

1. יגדיר קהל, החלטה וגבולות ראיות לפני עיצוב השקפים.
2. יבנה נרטיב בעל מסר מרכזי אחד לכל שקף.
3. יפריד טענות נתמכות מהנחות ומשאלות פתוחות.
4. יגדיר רכיבים חזותיים לפי מטרתם ההסברית ולא כקישוט.
5. יבקר מצגת שנוצרה בעזרת AI ויזהה חזרות, טענות שאינן נתמכות ומעברים חלשים.

## רצף ההוראה

1. בקשו מהתלמיד לנסח את ההחלטה המבוקשת במשפט אחד.
2. עברו על הערות המקור וסמנו עובדות, הנחות וראיות חסרות.
3. נסחו רק את כותרות השקפים ואת משפטי המסר המרכזי.
4. הוסיפו ראיות ותקצירי רכיבים חזותיים לאחר שהנרטיב עובד.
5. צרו או בנו מצגת, ואז הפעילו את רשימת הביקורת.
6. עדכנו שקף חלש אחד והסבירו מדוע הגרסה החדשה טובה יותר.
