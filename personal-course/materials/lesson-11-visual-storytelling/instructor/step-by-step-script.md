# Step-by-Step Instructor Script — Lesson 11

**Duration:** 20–30 minutes  
**Goal:** Help the student create a truthful, organized visual story while applying consent, provenance, and privacy checks.

## Definitions

- **Story spine:** The sequence of beats that gives the story direction.
- **Provenance:** Where an image, clip, or claim came from.
- **Generated asset:** New media created by an AI tool rather than captured during the event.
- **Consent:** Permission to use or transform media involving another person.
- **Authenticity boundary:** The line between creative presentation and falsely implying that something happened.

## Before the lesson

1. Ask the student to prepare 5–10 safe source images.
2. Open the activity and storyboard workbook.
3. Confirm the student has a basic editor available; no specific paid tool is required.
4. Avoid uploading identifiable people without consent.

## 0–3 minutes — Hook

Show or describe two versions of the same memory: a random photo dump and a five-frame story.

Say:

> “AI can help organize and style memories, but it should not invent memories.”

## 3–6 minutes — Audience and format

Have the student define audience, purpose, and one format. Ask:

- Is this private, shared with friends, or public?
- What should the viewer understand or feel?
- What platform constraints matter?

Checkpoint: one audience and one format are chosen.

## 6–10 minutes — Organize sources

Create or describe the folder structure. Explain why originals remain unchanged.

Have the student review each selected image for:

- permission
- private information
- location or identity exposure
- whether it actually supports the story.

## 10–15 minutes — Build the story spine

Require 4–6 beats. Read them aloud in order. Ask:

- Does each beat add something new?
- Is there an opening, development, and ending?
- Which source proves each beat?

Reject a beat that depends on an invented event.

## 15–20 minutes — Create one generated asset

The student writes one prompt for a title card, transition, texture, or illustration. Require an explicit authenticity boundary.

Good example: a decorative map illustration labelled as an illustration.

Bad example: a realistic image showing the group at a location they never visited.

## 20–25 minutes — Caption and provenance check

For each frame, require:

- truthful caption
- original/edited/generated status
- correct date or location where relevant
- permission and privacy status.

Ask the student to identify the frame most likely to mislead a viewer and improve its label or caption.

## 25–30 minutes — Final review

Run the checklist for consent, private details, licensing, spelling, export format, and saved project files.

## Minimum acceptable work

- defined audience and format
- organized source-media plan
- 4–6 beat storyboard
- one responsible generation prompt
- provenance-aware captions
- completed consent, privacy, and authenticity check.

## Common interventions

- **Student wants many generated scenes:** Limit the lesson to one generated support asset.
- **Student uses generated media as evidence:** Add a visible label or replace it with a real source.
- **Student focuses only on effects:** Return to the story spine.
- **Student shares private information:** Stop and redact before continuing.

## Exit check

Ask:

> “What is the difference between improving the presentation of a memory and changing what the viewer believes happened?”
