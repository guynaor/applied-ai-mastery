# Real Life Mission 10 — Design for a Real Space

**Ability unlocked:** Parametric Designer

Measure one real interface in your room and design a small organizer, stand, spacer, shelf concept, hook, or holder. Do not use the exercise as the sole basis for load-bearing, electrical, fire-safety, or child-safety decisions.

## Bronze — Build from measurements

Create a design contract containing the need, interface measurements, constraints, parameters, and assumptions. Update the OpenSCAD starter or create an equivalent simple model.

## Silver — Validate four configurations

Render and inspect:

1. default dimensions;
2. changed set A;
3. changed set B;
4. an extreme but plausible set.

Record pass/fail checks for geometry, clearances, wall thickness, usability, and printability or manufacturability. Keep measured, specified, assumed, and derived values distinct.

## Gold — Prototype responsibly

Create a cardboard mock-up, low-risk print, or scale test. Compare physical results with the model and revise one parameter. Do not test unsafe loads.

## Evidence to submit

- photographs or sketch with private details removed;
- design contract;
- source CAD file;
- four validation screenshots and log;
- prototype observations if attempted;
- completed journal entry.

## Reflection

1. Which measurement mattered most?
2. Which assumption was weakest?
3. What did rendering prove—and not prove?
4. What physical test would be required before real use?

## Instructor check

Look for parameter-driven changes, organized evidence, and honest validation boundaries. A model that merely renders is not automatically safe or functional.
