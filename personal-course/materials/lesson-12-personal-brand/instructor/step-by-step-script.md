# Step-by-Step Instructor Script — Lesson 12

**Duration:** 25–30 minutes  
**Goal:** Help the student turn genuine evidence into a targeted CV, profile, and portfolio while preventing exaggeration.

## Definitions

- **Evidence bank:** A structured list of real experiences, actions, tools, outputs, and results.
- **Transferable skill:** A demonstrated ability useful in another context.
- **Tailoring:** Selecting and emphasizing relevant evidence for a specific audience.
- **Claim:** A statement about experience, skill, responsibility, or result.
- **Portfolio artifact:** A shareable output that demonstrates work.
- **Application tracker:** A record of roles, versions, deadlines, status, and follow-up actions.

## Before the lesson

1. Open the activity and portfolio workbook.
2. Ask the student to bring one real or sample opportunity description.
3. Make sure course artifacts from earlier lessons are accessible.
4. Explain that unsupported claims must be removed, not polished.

## 0–3 minutes — Hook

Say:

> “A strong CV is not a collection of impressive adjectives. It is a clear map from what an opportunity needs to evidence you can honestly show.”

Ask the student to name one project from the course they could show another person.

## 3–8 minutes — Build the evidence bank

Require at least three projects or experiences. For each ask:

- What did you personally do?
- Which tools did you actually use?
- What artifact exists?
- What was checked or tested?
- Is there a measured result, or only an output?

Correct vague entries such as “worked on AI.” Replace them with observable actions.

## 8–12 minutes — Analyze the target

Extract 5–8 requirements from the opportunity. Label each required or preferred.

Ask:

- Which requirement has direct evidence?
- Which has partial evidence?
- Which is a genuine gap?

Do not convert interest into experience.

## 12–17 minutes — Use AI for evidence mapping

Run the evidence-mapping prompt. Review the response line by line.

For every proposed claim ask:

> “Where is the evidence?”

If the student cannot point to a source, revise or remove the claim.

## 17–22 minutes — Draft one project entry

Build one project entry from problem, action, tool, artifact, verification, and limitation.

Require active but accurate verbs. Distinguish:

- **built** from **planned**
- **tested** from **considered**
- **used** from **familiar with**
- **measured** from **estimated**.

## 22–25 minutes — Create profile and portfolio index

Draft a 3–4 line profile. Then choose 2–4 portfolio projects.

For each project require:

- a clear problem
- the student’s contribution
- visible artifact
- tools
- verification
- limitation.

## 25–28 minutes — Application tracking

Create one tracker row with role, source, deadline, CV version, status, follow-up date, and next action.

Explain that version naming and follow-up dates are part of professional digital-life management.

## 28–30 minutes — Exit check

Ask:

1. What is the difference between tailoring and exaggerating?
2. Which claim in the draft has the strongest evidence?
3. Which gap should remain visible?

## Minimum acceptable work

- evidence bank with at least three entries
- target-role requirement map
- one evidence-checked project entry
- truthful short profile
- 2–4 project portfolio index
- application tracker with follow-up date.

## Common interventions

- **Student adds unsupported impact numbers:** Ask for the measurement; remove the number if none exists.
- **Student copies the job description into the CV:** Return to personal evidence.
- **Student hides a skill gap:** Label it honestly and identify a learning action.
- **Student lists projects without artifacts:** Add a screenshot, file, link, or concise case-study note.
- **Student exposes private data:** Remove it before sharing.
