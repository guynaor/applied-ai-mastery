# Real Life Mission 1 — Use Better Requests in the Wild

**Ability unlocked:** Asking Better Questions

Use AI for a genuine task on three different occasions before the next lesson. Choose low-risk tasks such as cooking, studying, organizing, writing, hobbies, or recommendations. Do not submit private health, financial, identity, or account information.

## Bronze — Improve one real request

1. Save your first prompt and response.
2. Rewrite the prompt with clearer context, constraints, and output format.
3. Compare the two responses.
4. Verify one important detail.

## Silver — Test a reusable pattern

Repeat the process for three different real tasks. Use the same prompt structure each time and record which parts transferred well.

## Gold — Teach the pattern

Help another person improve one of their prompts. Record what you changed and whether the result improved.

## Evidence to submit

- original and improved prompt
- short output comparison
- verification evidence
- one reusable prompt pattern with private details removed
- completed journal entry.

## Reflection

1. Which added detail improved the answer most?
2. What did AI still misunderstand?
3. When would this prompt pattern be unsafe or unsuitable?
4. What will you save in your prompt library?

## Instructor check

Look for a meaningful controlled improvement, not merely a longer prompt. The student should be able to explain why the result changed and how one claim was checked.
