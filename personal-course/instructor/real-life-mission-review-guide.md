# Instructor Guide — Reviewing Real Life Missions

The Real Life Missions reinforce transfer: students use the lesson skill on a genuine task outside the classroom. Review the quality of the process, not whether the purchase, trip, design, or decision turned out perfectly.

## Submission method for the MVP

Agree on one external channel before the course begins, such as:

- a shared Google Drive folder
- Google Classroom
- email
- a private GitHub repository
- a shared document
- an existing learning platform

Ask students to use consistent names:

`student-name / lesson-number / mission-level`

Do not require sensitive personal information. Accept redacted screenshots and anonymized examples.

## One-minute review checklist

Mark each item as `Not yet`, `Demonstrated`, or `Strong`.

| Check | Rating | Note |
|---|---|---|
| Mission requirements completed | | |
| Evidence is understandable and organized | | |
| AI output was checked rather than trusted blindly | | |
| Student identified uncertainty or a limitation | | |
| Reflection explains what changed in their thinking | | |
| Work is truthful and respects privacy/consent | | |

## Feedback pattern

Use three short lines:

1. **Strongest evidence:** name the clearest demonstrated skill.
2. **Biggest coaching opportunity:** name one specific improvement.
3. **Next experiment:** suggest one small action, not a complete redo.

## When to request revision

Request a focused revision when:

- the submission contains only an AI output with no evidence of student judgment
- factual claims are presented without checking
- the student cannot explain their prompt or decision
- personal data, private images, or other people’s information was shared unnecessarily
- a result is described as working without a meaningful test
- an investment exercise becomes personalized financial advice or a return prediction

Do not require a full restart. Ask for the smallest revision that demonstrates the missing skill.

## Mission levels

- **Bronze:** approximately 15 minutes; minimum transfer task.
- **Silver:** approximately 30–45 minutes; a real problem with stronger evidence.
- **Gold:** optional, open-ended, often involving another person, a deployed artifact, or teaching the skill.

Bronze is sufficient for course completion. Silver is the normal target. Gold should be recognized but never required when time, money, access, safety, or privacy make it impractical.

## XP for the browser-only MVP

The portal may display local XP as motivation:

- lesson complete: 20 XP
- Bronze mission: 30 XP
- Silver mission: 50 XP
- Gold mission: 80 XP
- journal entry: 20 XP

XP is self-recorded in the learner’s browser and is not a grade or verified record. Instructor assessment remains based on submitted evidence.

## End-of-course evidence

Ask each student to select 3–5 strong artifacts and explain:

- the problem
- their role
- how AI helped
- how they verified or tested the work
- what they changed after feedback
- what remains limited

This becomes the evidence base for Lesson 12 rather than a collection of unsupported claims.
