Test cards — Session 4

The tool you built works. The only question left is where it breaks. Cut out or project these cards, and let each learner draw one once the normal case passes.

One rule: a card that makes the tool behave strangely is a successful test, not a failed tool. Record what happened, fix one thing, and test again.

The first card — always

The normal case

The action you built the tool for, exactly as you intended it.

If this does not work, there is no point drawing the rest.

Input cards

Empty

Press “add” without typing anything.

Did a blank row appear? Is there a message explaining what is missing?

Zero

Enter 0 in a field expecting a number.

Zero is a legitimate value. Does the tool treat it as nothing entered?

Negative number

Enter -25.

Does that even make sense in your tool? If not, does it prevent it or just calculate?

Text where a number goes

Type “thirty” into an amount field.

Does the result become NaN? Is there a message? Or does the row silently vanish?

Far too long

Paste a whole paragraph into a name field.

Does the layout break? Can you still reach the buttons?

Fractions of a penny

Enter 33.333, or divide 100 by three.

How many decimal places show? Do the amounts still add up together?

State cards

The same thing twice

Add the same item or the same name twice.

Two separate rows? Merged? A message?

Delete everything

Remove every item, then look at the result.

What shows with no data — an empty screen, a zero, or an error?

Refresh the page

Reload the browser after entering data.

Everything gone? That is fine — but does the user know that in advance?

Reset by accident

Press “reset” while there is data in it.

Is there a confirmation before deleting? If not, are you happy with that?

Boundary cards — for anyone who finishes early

Only one person

In a cost-splitting tool: enter a single participant.

Divide by one, or divide by zero and error?

Narrow screen

Shrink the browser window to phone width.

Is it still usable? That is where you will actually use it.
