01 · OpeningMinutes 10–20

What do you redo on a scrap of paper every month, and always lose?

We build a solution twice today: a tiny one in chat, and a real application. The comparison is the lesson.

02 · Shrink itMinutes 10–20

One user, one problem, at most three actions

Who
one person, named, not “users”
What
the one thing they redo every month
Actions
three at most
Forbidden
what it must never do

Every fourth action costs you a test you will not run — doubly so today, because we build it twice.

03 · The tiny versionMinutes 20–35

The cheap, fast one first

The full request
Build one self-contained web page for splitting costs between three flatmates. Three actions only: add an expense, see who owes whom, clear the month. No sign-in, no server, everything in one file.

04 · Get it outMinutes 20–35

An artifact that only runs inside the tool is not yours yet

  1. Download it, or copy the code into a file.
  2. Open it by double-clicking. It should run with no internet.
  3. If it breaks, it is usually a file that did not come down with it.

05 · TestingMinutes 35–45

The normal case first. Only then a card.

Expected

“Dana owes Yossi 75”

Actual

Showed 150 — never divided

A card that broke the tool is a test that succeeded.

07 · Added unaskedMinutes 45–70

“I asked for two screens. How many are here?”

The platforms add a lot you never requested — including sign-in, which quietly makes it an account system.

Not a fault. But it is now yours to explain to anyone you invite.

08 · ControlMinutes 70–80

Four decisions before you send it to anyone

Stored where
a file on my machine, or somebody else’s server
Opened by whom
whoever has the file, or whoever has the link
Cleared how
delete the file — or something that only looks like deletion
If you stop paying
the file stays with you. The rest is a good question

09 · The limitMinutes 70–80

What we are not building

  1. No passwords and no account details.
  2. No other people’s data without their knowing.
  3. No decisions with financial or medical weight.

10 · Exit checkMinutes 80–90

And the question worth sitting with
