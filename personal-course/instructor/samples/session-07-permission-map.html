Sample permission map — Session 7

The material for the permission demonstration. It works without installing anything: this session is about what you approve, not about installation.

Do not connect a tool to a learner's account, and do not use real files. The folder below is entirely invented.

Two text files, two photos, and an archive folder. Nothing personal is in it — and that is the point. The demonstration folder is chosen so that even a mistake costs nothing.

The permission request — read it before approving

Claude Desktop is requesting access

The application is requesting:

  • Read and write across your entire Documents folder
  • Access to recently opened files
  • Running actions without separate approval for each
Choose a specific folder Allow

The right button is the quiet one, not the prominent one. Interfaces are designed so the broad approval is the easiest path. That is not malice — it is a default that suits whoever built it, which is exactly why the decision has to be yours rather than the design's.

What to approve and what not to

The requestDecisionWhy
Read the garden-project folderYesExactly what the task needs, and no more
Read the whole Documents folderNoThe task does not require it. Convenience is not a reason
Write or delete in the folderNoToday is read-only. Writing stays with us
Recently opened filesNoThat is a list of everything you have done, not of the project
Running without per-action approvalNoThe approval point is all that separates a proposal from an action

The demonstration request

In the selected sample folder only: list the file names, and draft one
opening sentence for the project page. Do not change, delete, move, upload,
or share anything, and do not go outside this folder. Ask for approval before
any action, and state what you were unable to see.

After the run — what to check

The checkWhat to look for
The file namesDoes the list match exactly what is in the folder?
What stayed outDid it try to touch the archive, or anything outside the folder?
The draftDoes it rest on what it saw, or on a generic guess?
DisconnectingDid you remove the access at the end of the demonstration?
