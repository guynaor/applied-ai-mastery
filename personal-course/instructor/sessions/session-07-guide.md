# Session 7 facilitator guide — Build a Personal System

## Preparation and timing

Prepare a non-sensitive sample folder containing two dummy notes and a fictional project goal. Teach: evidence 10 minutes; launchpad 12; permissions demo 15; boundary map 10; review 8 (55 total).

## Default demonstration

Use Claude Desktop with: **“In the selected sample folder only, list the filenames and propose a one-sentence project launchpad from their contents. Do not change, move, upload, share, or open anything outside this folder. Ask for approval before any action.”** Expected intermediate artifact: evidence register and proposed launchpad.

## Equivalent tool routes

**Claude:** demonstrate Claude Desktop only on the prepared non-sensitive folder. **ChatGPT:** use pasted dummy-note text and the same launchpad request. **Gemini:** use pasted dummy-note text and the same request. No learner needs to connect a desktop tool.

## Visible verification and teaching notes

Before connecting, show requested permissions and grant the **least privilege**—only the sample folder. Confirm filenames/results, then disconnect or retain no broader access. Misconceptions: convenience justifies broad access; an agent can send messages or decide outcomes. No-paid/no-tool alternative: paper permission map and evidence register. **Claude for Chrome** is further exploration only: start read-only and never authorise account changes, payments, messages, or private data. **OpenClaw** is paper-only: do not install, connect, deploy, or run it.

## Review prompts

What is the smallest access needed? What always requires human approval? What evidence supports each portfolio claim? When does the system stop?
