# Session 6 facilitator guide — Tell a True Visual Story

## Preparation and timing

Prepare a consented or public-photo mini story and one clearly labelled illustrative image. Teach: boundary 8 minutes; evidence sort 10; storyboard 15; accessibility/trust review 15; reflection 7 (55 total).

## Default demonstration

Use ChatGPT with: **“From these non-sensitive notes about a community garden visit, draft a six-panel storyboard with short captions and alt text. Mark which claims need a source and do not invent photographs or say a generated image is documentary evidence.”** Expected intermediate artifact: labelled storyboard.

## Equivalent tool routes

**ChatGPT:** use the default request. **Claude:** use the same request. **Gemini:** use the same request. A hand-drawn storyboard is valid.

## Visible verification and teaching notes

Show the source/permission record beside an image and read alt text aloud. Ask whether a viewer could mistake an illustration for a real event. Misconceptions: captions do not need checking; public image means permission. No-paid/no-tool alternative: paper panels, manual captions, and a source list.

## Review prompts

What is factual, illustrative, or edited? Who consented? Can a screen-reader user understand the story?
