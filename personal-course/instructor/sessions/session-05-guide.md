# Session 5 facilitator guide — Make a Space Work Better

## Preparation and timing

Prepare a small box, ruler, paper, and fictional desk-drawer measurements. Teach: measure 12 minutes; constraints 12; model 15; fit test 10; reflection 6 (55 total).

## Default demonstration

Use Gemini with: **“Turn these measured drawer and cable dimensions into a non-safety-critical organiser brief. Separate measured values, assumptions, clearances, and one adjustable parameter. Do not claim engineering or safety approval.”** Expected intermediate artifact: labelled parameter sheet.

## Equivalent tool routes

**Gemini:** use the default request. **Claude:** use the same request. **ChatGPT:** use the same request. A sketch plus ruler is complete.

## Visible verification and teaching notes

Measure a real object on camera/in class and compare it with the sheet. Test a paper mock-up for the key fit. Misconceptions: a render proves fit; assumed dimensions equal measurements. No-paid/no-tool alternative: paper sketch and cardboard fit test.

## Review prompts

Which dimension matters most? What is assumed? What would make this inappropriate to build?
