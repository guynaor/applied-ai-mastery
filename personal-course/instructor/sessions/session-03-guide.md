# Session 3 facilitator guide — Make a Shared Plan Work

## Preparation and timing

Prepare a fictional one-day outing with a public timetable, opening hours, and a budget. Teach: constraints 10 minutes; evidence 10; plan 15; disruption test 15; reflection 5 (55 total).

## Default demonstration

Use ChatGPT with: **“Organise this non-sensitive one-day outing using only the facts below. Put fixed commitments first, add travel and a 30-minute buffer, assign an owner to each task, and propose one fallback for rain. Mark unknowns; do not invent availability.”** Expected intermediate artifact: a dated schedule with owners.

## Equivalent tool routes

**ChatGPT:** use the default request. **Claude:** use the same facts and request. **Gemini:** use the same facts and request. Learners can make the plan on paper.

## Visible verification and teaching notes

Check the timetable and opening hours against their public pages. Introduce a late-arrival scenario and visibly revise the plan. Misconceptions: preferences are constraints; an itinerary has no owner. No-paid/no-tool alternative: sticky-note schedule plus a printed source.

## Review prompts

What changes if one person is late? Which fact must be rechecked? Who decides when preferences conflict?
