# שיעור 1 — לבקש טוב יותר ולקבל תוצאה טובה יותר

**מיומנות שנפתחת:** Asking Better Questions

## מתחילים כאן — מפת עולם ה-AI, עשר דקות

קראו את [מפת עולם ה-AI בעשר דקות](ai-geography.md).

ודאו שאתם יכולים להסביר:

1. מה ההבדל בין LLM לבין אפליקציית AI;
2. האם הוראות חוזרות לתהליך עבודה הן prompt, artifact או skill;
3. למה agent זקוק לבדיקת הרשאות קפדנית יותר מתשובת טקסט בלבד.

בהמשך השיעור נעבוד עם היחידה הקטנה ביותר: בקשה ברורה אחת בצ'אט רגיל.

## מושגים

- **LLM** — המנוע הבסיסי שמייצר תוכן מדפוסים שנלמדו.
- **AI application** — מוצר שמשלב מודל אחד או יותר עם ממשק ויכולות נוספות.
- **Artifact** — תוצר משמעותי שאפשר לשמור, לערוך, לשתף או להשתמש בו שוב.
- **Skill** — הוראות, הקשר ומשאבים לשימוש חוזר שמגדירים תהליך עבודה.
- **Agent** — מודל שפועל להשגת מטרה באמצעות תכנון, כלים, בדיקת תוצאות והתאמה תחת פיקוח אנושי.
- **Prompt** — הבקשה שאנחנו נותנים למערכת AI.
- **Context** — מידע רקע שעוזר להבין את המצב.
- **Constraints** — מגבלות ודרישות שחייבים לכבד.
- **Output format** — הצורה שבה נרצה לקבל את התוצאה.
- **Iteration** — שיפור הדרגתי של הבקשה לאחר בדיקה.

## פעילות תלמיד — 20 דקות לאחר המבוא

1. בחרו משימה יומיומית קטנה ולא רגישה: תכנון ארוחה, לימוד נושא, כתיבת הודעה או ארגון זמן.
2. כתבו בקשה ראשונית קצרה כ-**Prompt A** ושמרו את הפלט.
3. זהו מה חסר: מטרה, קהל, הקשר, אילוצים, דוגמה או פורמט.
4. כתבו גרסה משופרת באנגלית כ-**Prompt B**:

```text
I need help with [goal].
Context: [relevant background].
Constraints: [time, budget, limits, things to avoid].
Please produce: [specific output format].
Before answering, list any important missing information.
```

5. השוו בין Prompt A ל-Prompt B. שנו רק רכיב אחד נוסף והריצו שוב כ-**Prompt C**.
6. אמתו פרט חשוב אחד במקור אחר.

## תוצר לשיעור

- הפרומפט הראשון;
- הפרומפט המשופר;
- שינוי מבוקר אחד;
- השוואה קצרה;
- פרט אחד שאומת.

## משימת חיים אמיתית

**Bronze:** שפרו בקשה אמיתית אחת, השוו ואמתו פרט.

**Silver:** השתמשו באותה תבנית בשלוש משימות שונות וכתבו מה עבר היטב בין התחומים.

**Gold:** עזרו לאדם אחר לשפר פרומפט ותעדו מה השתנה.

הגישו פרומפטים ללא מידע פרטי, השוואה, ראיית אימות ורישום ביומן.

## למורה — תסריט קצר

- **0–8 דקות:** עברו על model, application, tools, artifact, skill ו-agent בעזרת המפה. מקמו את המוצרים כדוגמאות עכשוויות ולא כדירוג קבוע.
- **8–10 דקות:** שאלו מה ההבדל בין מערכת שמנסחת הודעה לבין agent ששולח אותה. עברו לבקשה אחת בצ'אט רגיל.
- **10–13 דקות:** הדגימו בקשה עמומה ולמדו בקצרה מטרה, הקשר, אילוצים, פורמט ובדיקה.
- **13–19 דקות:** התלמידים כותבים Prompt A ו-Prompt B.
- **19–24 דקות:** מריצים ומשווים בעזרת הבדל ממשי אחד.
- **24–27 דקות:** משנים רכיב אחד בלבד ויוצרים Prompt C.
- **27–30 דקות:** שומרים תבנית ללא מידע פרטי ומבצעים בדיקת יציאה.

### תשובות צפויות

שיפורים טובים כוללים קהל ברור, תקציב, זמן, דברים להימנע מהם ופורמט מוגדר. פרומפט ארוך יותר אינו בהכרח טוב יותר.

### בדיקת הבנה

התלמיד מסוגל להסביר למה התוצאה השתנתה, ולא רק לומר שהגרסה השנייה ״טובה יותר״.
