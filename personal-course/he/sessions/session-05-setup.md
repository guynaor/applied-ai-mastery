## מסלול 1 — OpenSCAD (לכולם)

OpenSCAD בונה מודל תלת־ממדי מתוך הוראות כתובות, במקום גרירה עם עכבר. זה נשמע קשה יותר ולמעשה קל יותר, כי AI יכול לכתוב את ההוראות במקומכם ואתם יכולים לקרוא אותן.

### התקנה

- **מק:** הורידו מ-[openscad.org/downloads](https://openscad.org/downloads.html), פתחו את קובץ ה-`dmg` וגררו את OpenSCAD לתיקיית Applications. בפתיחה הראשונה macOS עלול לסרב כי המפתח אינו מזוהה — לחצו קליק ימני על האפליקציה, בחרו **Open** ואשרו.
- **חלונות:** הורידו את קובץ ההתקנה מאותו דף והריצו אותו. אפשר לאשר את כל ברירות המחדל.

### בדיקה

פתחו את OpenSCAD. אתם אמורים לקבל חלון שמחולק לשלושה: עורך טקסט משמאל, תצוגה תלת־ממדית מימין, וקונסולה למטה. הדביקו בעורך את השורה הזאת ולחצו **F5**:

```
cube([30, 20, 10]);
```

**אתם אמורים לראות** תיבה מלבנית מופיעה בתצוגה. אם ראיתם אותה, מסלול 1 הושלם — אתם לא צריכים שום דבר נוסף למפגש.

### נסו את קובץ ההתחלה

הורידו את [`session-05-organiser.scad`](../../instructor/samples/session-05-organiser.scad) ופתחו אותו ב-OpenSCAD. לחצו F5. אתם אמורים לראות מארגן מגירה עם חמישה תאים, ובקונסולה אמור להופיע הרוחב של כל תא. שנו את `compartments = 5;` ל-`7`, לחצו F5 שוב, וראו איך התאים נעשים צרים יותר.

זה כל הרעיון של המפגש: **משנים מספר אחד, ורואים מה זז.**

## מסלול 2 — FreeCAD, ה-MCP ו-Claude Desktop

המסלול הזה מאפשר לדבר עם FreeCAD בשפה רגילה ולראות את המודל משתנה. יש בו שלושה חלקים, וצריך לעשות אותם לפי הסדר.

### 2א. התקנת FreeCAD

- **מק:** הורידו מ-[freecad.org/downloads](https://www.freecad.org/downloads.php), פתחו את ה-`dmg` וגררו את FreeCAD ל-Applications. בפתיחה הראשונה — קליק ימני ו-**Open** אם macOS מתנגד.
- **חלונות:** הורידו את קובץ ההתקנה מאותו דף והריצו אותו.

**בדיקה:** FreeCAD נפתח ומציג דף פתיחה, ולמעלה יש רשימה נפתחת של סביבות עבודה. צרו מסמך ריק חדש (`File > New`). אתם אמורים לקבל תצוגה תלת־ממדית ריקה עם קובייה לניווט בפינה.

### 2ב. התקנת ה-MCP של FreeCAD

ה-MCP הוא מה שמאפשר לעוזר AI לראות את המסמך שלכם ולשנות אותו. יש לו **שני חצאים**, וכאן אנשים נתקעים:

1. **תוסף בתוך FreeCAD**, שפותח שרת קטן כדי שמשהו מבחוץ יוכל לדבר איתו.
2. **שרת MCP על המחשב**, שאליו מתחבר עוזר ה-AI שלכם.

**שניהם חייבים לרוץ.** עקבו אחרי הוראות ההתקנה בדף של הפרויקט עצמו — [github.com/neka-nat/freecad-mcp](https://github.com/neka-nat/freecad-mcp) — כי הן משתנות בין גרסאות, והעתק ישן של השלבים גרוע יותר מלא להעתיק בכלל.

בגדול: מתקינים את התוסף לתיקיית `Mod` של FreeCAD (הפרויקט מסביר איפה היא בכל מערכת), מפעילים מחדש את FreeCAD, ואז רושמים את שרת ה-MCP אצל עוזר ה-AI.

**בדיקה:** פתחו את FreeCAD וחפשו את סביבת העבודה של התוסף ברשימה הנפתחת. הפעילו את השרת שלו — בדרך כלל כפתור או פריט תפריט בנוסח „Start RPC Server”. בחלון הדוחות של FreeCAD אמורה להופיע הודעה שהשרת עלה, עם מספר פורט.

> **התקלה שכולם נתקלים בה:** ה-AI אומר שהוא לא מצליח להתחבר, או שמופיע `Connection refused`. כמעט תמיד זה אומר ש**FreeCAD לא פתוח**, או שהשרת של התוסף מעולם לא הופעל בתוכו. שרת ה-MCP לבדו אינו מספיק — FreeCAD חייב לרוץ כשהשרת שלו דלוק. בדקו את זה לפני שאתם מנפים משהו אחר.

### 2ג. חיבור Claude Desktop

התקינו את Claude Desktop מ-[claude.ai/download](https://claude.ai/download), התחברו, והוסיפו את שרת ה-MCP של FreeCAD להגדרות. ב-Claude Desktop יש מסך הגדרות לשרתי MCP, ובדף הפרויקט מופיעה בדיוק הרשומה שצריך להדביק.

**בדיקה:** כש-FreeCAD פתוח והשרת שלו רץ, בקשו מ-Claude Desktop: *„רשום את המסמכים הפתוחים ב-FreeCAD.”* הוא אמור להחזיר את שם המסמך שיצרתם, לא שגיאה.

## מסלול 3 — Claude Code או Antigravity

שווה רק למי שנוח לו עם טרמינל או עורך קוד. את כל מה שיש במפגש אפשר לעשות במסלולים 1 ו-2.

### Claude Code

דורש [Node.js](https://nodejs.org) מותקן קודם, וחשבון Claude עם מנוי בתשלום או קרדיטים ל-API. הוראות ההתקנה וההתחברות נמצאות ב-[claude.com/claude-code](https://claude.com/claude-code).

**בדיקה:** פתחו טרמינל, הריצו `claude`, וודאו שהוא עולה ומקבל בקשה. אחר כך הוסיפו לו את ה-MCP של FreeCAD ובקשו ממנו לרשום את המסמכים הפתוחים.

### Antigravity

עורך סוכני של Google. הוראות ההורדה וההתחברות נמצאות בדף הרשמי שלו — **בדקו את הדף העדכני ולא שלבים משוננים מהזיכרון**, כי הכלי חדש ומשתנה מהר.

**בדיקה:** הוא נפתח, אתם מחוברים, והוא מצליח לפתוח תיקייה שמכילה את קובץ ה-`scad` שלכם.
