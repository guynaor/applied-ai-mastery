# Applied AI Mastery Capstone — AquaNode Mini

The capstone integrates all seven course sessions into one bounded product-development decision.

## Mission

AquaForge leadership is considering whether to proceed from the existing AquaNode Mini concept to a controlled engineering-validation pilot. The student acts as the **Lead Applied AI Engineer** and must produce a traceable recommendation without presenting estimates, AI-generated content, or rendered geometry as verified fact.

## Skills integrated

1. Structured prompting and model comparison
2. Evidence-based research and citation checking
3. Spreadsheet cleanup and automation design
4. Decision-oriented presentation design
5. Constraint-based operational planning
6. Bounded monitoring-agent specification
7. Parametric CAD and validation

## Folder structure

- `student/AF-CAP-001-mission-brief.md` — full assignment
- `student/AF-CAP-002-evidence-register.csv` — evidence and uncertainty tracker
- `student/AF-CAP-003-deliverable-register.csv` — submission checklist
- `student/AF-CAP-004-decision-log.csv` — decisions, assumptions, and changes
- `instructor/AF-CAP-101-instructor-guide.md` — facilitation and answer guidance
- `instructor/AF-CAP-102-rubric.csv` — weighted assessment rubric

## Completion standard

The capstone is complete only when the recommendation, evidence register, calculations, presentation, automation design, CAD validation, and unresolved-risk list agree with one another. Attractive output is not a substitute for traceability.
