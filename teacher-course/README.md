# Applied AI Mastery — Teacher Track

This bilingual course helps K–12 teachers use AI as a draft, research, analysis, and design partner while keeping instructional judgment with the teacher. English materials are canonical; Hebrew translations present the same learning path. Work artifacts remain in English where formulas or reusable templates require it.

Every scenario and data set is fictional. Do not upload student names, records, IEP/504 information, family contact details, or any protected data. AI may suggest drafts and patterns, but it must not autonomously grade work, place learners, make behavior decisions, select interventions, or send communications. A teacher verifies standards, accuracy, age suitability, accessibility, and every consequential decision.

The seven missions build toward a teacher-reviewed K–12 water unit capstone. Each includes student materials, an instructor script, guide, answer key, and rubric. Keep evidence of prompts, sources, checks, privacy decisions, and the next improvement in the learning journal.
