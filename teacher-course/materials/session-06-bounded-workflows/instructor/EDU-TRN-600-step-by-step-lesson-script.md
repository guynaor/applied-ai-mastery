# EDU-TRN-600 — Step-by-Step Lesson Script

## Outcome

Learners can specify a narrowly bounded unattended monitoring workflow whose only output is a teacher-reviewed private draft.

## 70-minute flow

1. **10 min — Frame the boundary.** Contrast monitoring public curriculum snapshots with automating classroom decisions. State the prohibited domains: grades, behavior, placement, intervention, and external messages.
2. **15 min — Trace inputs.** Inspect the fictional CSV and identify why the private row must stop the workflow.
3. **20 min — Build state logic.** Learners complete ID/hash duplicate and changed-item rules.
4. **15 min — Test failure cases.** Run the test-log scenarios mentally and require an audit-log field for each.
5. **10 min — Review gate.** Learners explain why a teacher must verify source changes and approve any future sending/publishing.

## Check for understanding

Ask: “What happens if a changed snapshot looks relevant but no teacher has checked the original source?” Expected answer: it stays a cited, uncertain draft in pending approval; it does not change a plan or leave the system.
