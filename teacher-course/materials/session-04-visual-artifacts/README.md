# Mission 4 — Classroom Presentations and Visual Learning Artifacts

## Purpose

Create a six-slide, evidence-aware classroom deck for the fictional inquiry **Local Water, Shared Responsibility**. AI may propose language or a storyboard; the teacher verifies every fact, source, image, caption, accessibility choice, and developmental fit before use.

## Deliverables

1. Complete the presentation brief and source notes.
2. Plan six slides in the storyboard CSV, including spoken narration and alt text.
3. Submit the accessibility and age-appropriateness critique.

Use only public, district-approved, or teacher-created materials. Do not use student photos, names, work, or AI-generated “facts” without verification.

## Package map

- `student/EDU-COM-401-presentation-brief.md` — scenario and six-slide brief
- `student/EDU-COM-402-source-notes.md` — source and claim record
- `student/EDU-COM-403-storyboard-template.csv` — planning sheet
- `student/EDU-COM-404-accessibility-critique.md` — preflight critique
- `instructor/` — facilitation, guide, answer key, and rubric
