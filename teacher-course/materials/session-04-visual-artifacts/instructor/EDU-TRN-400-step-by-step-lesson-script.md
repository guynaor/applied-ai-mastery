# EDU-TRN-400 — Step-by-Step Lesson Script

**Time:** 70 minutes. **Outcome:** participants storyboard a six-slide deck and defend one revision using evidence and learner needs.

1. **0–8 min — Frame.** Say: “A polished deck is not automatically a trustworthy deck. Today the teacher is the verifier.” Display the six-slide sequence.
2. **8–18 min — Model.** Read the sample storyboard row. Ask what the diagram can show and what it cannot establish about the local water system.
3. **18–33 min — Source work.** Participants complete source notes for slides 2–3. Prompt: “What exactly does this source support?”
4. **33–48 min — Storyboard.** Pairs draft all six rows and select one grade band. Circulate using the guide questions.
5. **48–60 min — Critique swap.** Partners use EDU-COM-404. Each must identify one claim or visual to revise/remove.
6. **60–70 min — Share and exit.** Invite one K–2/3–5 adaptation and one 6–8/9–12 adaptation. Exit ticket: name a verification step AI cannot perform for the teacher.

If time is short, complete slides 1–3 and orally plan 4–6; do not skip source/alt-text review.
