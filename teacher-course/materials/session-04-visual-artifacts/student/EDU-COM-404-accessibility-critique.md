# EDU-COM-404 — Accessibility and Age-Appropriateness Critique

Review the proposed deck before teaching. Mark **ready**, **revise**, or **remove**, then explain the evidence for each decision.

| Check | Status | Evidence and revision |
| --- | --- | --- |
| Every factual claim has a source note and a teacher verification date. | | |
| Captions say what a visual proves and what it does not prove. | | |
| Alt text conveys learning meaning; decorative images are marked decorative. | | |
| Meaning is not carried by color alone; contrast, font size, and reading load work for the chosen learners. | | |
| Language, examples, and emotional tone fit the selected grade band. | | |
| Perspectives do not stereotype families, neighborhoods, or communities. | | |
| No image, chart, or AI text implies an unsupported local fact. | | |

## Required rejection

Identify one tempting visual or sentence to reject. Explain whether it is misleading, unsourced, inaccessible, developmentally inappropriate, or not useful for learning. Replace it with a safer alternative.
