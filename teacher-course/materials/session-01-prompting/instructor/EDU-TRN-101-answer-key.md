# EDU-TRN-101 — Answer Key

The vague prompt should usually omit grade, time, materials, access, and verification. A strong RISEN response names the selected band and constraints, but is still only a draft.

Expected teacher checks: confirm standards wording with the local curriculum; check factual claims and source dates; simplify language/visuals for K–2; ensure 3–5 maps are readable; require evidence citations for 6–8; and separate factual evidence from civic values for 9–12. Age appropriateness cannot be inferred reliably from generic AI language. Teachers retain authority for grouping, accommodations, and final instruction.
