# EDU-TRN-700 — Step-by-Step Lesson Script

## Outcome

Learners can adapt a dependency-free local resource hub while verifying accessibility, age fit, source status, and privacy.

## 70-minute flow

1. **10 min — Inspect the boundary.** Open the one-file hub locally and identify its no-data-collection statement.
2. **15 min — Inventory and age fit.** Choose a grade band and revise one resource for reading load and task complexity.
3. **20 min — Accessible interaction.** Navigate with keyboard only; test focus and the disclosure button; inspect the diagram alt text.
4. **15 min — Source and privacy review.** Verify each item is fictional/public; search the file for forms, remote URLs, trackers, and student fields.
5. **10 min — Teacher sign-off.** Learners complete the log and state one item that needs revision before sharing.

## Check for understanding

Ask: “Why does a local one-file page still require teacher review?” Expected answer: accessibility, age appropriateness, accuracy/source fit, and privacy are contextual and cannot be assumed from working code.
