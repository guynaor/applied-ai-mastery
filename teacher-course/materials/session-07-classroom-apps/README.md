# Mission 7 — Classroom Resources and Simple Apps

Build and evaluate a small, local classroom resource hub. The delivered scenario is a student-facing River Systems water-unit hub using only fictional/public materials. It runs from one file, has no dependencies, makes no network request, and collects no data.

## Variants

The same pattern could support vocabulary practice, a lab-group rotation board, a class resource hub, or a parent-night information page. Choose only an age-appropriate, privacy-preserving use. This mission’s starter hub is a resource hub, not a student tracker or decision tool.

## Deliverables

- `EDU-APP-701-resource-hub-brief.md`
- completed `EDU-APP-702-resource-inventory.csv`
- revised `EDU-APP-703-starter-resource-hub.html`
- completed `EDU-APP-704-accessibility-test-log.md`

## Required checks

Keyboard navigation, visible focus, readable contrast, meaningful alt text, age suitability, and no data collection are required. Do not add forms, analytics, logins, trackers, student names, or grade/behavior features.
