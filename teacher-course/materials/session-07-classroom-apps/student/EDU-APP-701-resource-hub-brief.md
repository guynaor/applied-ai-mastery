# EDU-APP-701 — Water-Unit Resource Hub Brief

## User and purpose

Create a simple student-facing hub for a fictional River Systems unit. It helps learners find a read/watch/do activity and understand how to use each resource. It is not a quiz, tracker, gradebook, messaging tool, or account system.

## Grade-band adaptation

| Grade band | Adaptation |
| --- | --- |
| K–2 | Use read-aloud wording, adult-supported activity cards, and a short visual routine. |
| 3–5 | Include guided vocabulary and a labeled watershed-model activity. |
| 6–8 | Add evidence prompts and a comparison task. |
| 9–12 | Add civic-source evaluation and an argument-planning prompt. |

## Requirements

- Keep the app in one local HTML file with embedded CSS and JavaScript; use no libraries or remote assets.
- Use only the provided fictional/public water materials. Name the source/status in the inventory.
- Provide logical keyboard navigation, a visible focus state, semantic headings/buttons, and readable contrast.
- Give every informative image meaningful alt text; decorative visuals must have empty alt text.
- Check reading load, claims, imagery, and task directions for the selected age band.
- Collect no data: no forms, analytics, cookies, accounts, names, saved responses, or network requests.

## Teacher review

Before sharing locally, inspect every link/text claim, test by keyboard, check contrast and alt text, and confirm that no data is collected. Record results in the accessibility test log.
