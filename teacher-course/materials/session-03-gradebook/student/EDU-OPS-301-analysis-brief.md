# EDU-OPS-301 — Fictional Gradebook Analysis Brief

Clean the supplied fictional data without deleting originals. Create a formula column that distinguishes numeric scores from blank/`NA`; do not convert missing work to zero. Calculate a grade-band average only after checking missingness, and flag patterns as questions for teacher review.

Write a communication-neutral brief: “The table suggests…; teacher should verify…; this does not establish….” Include one pattern for each relevant band and an accessible instructional follow-up option. Do **not** autonomously grade, place learners, make behavior decisions, or choose interventions.

No real names, IDs, protected information, or real grades may be used.
