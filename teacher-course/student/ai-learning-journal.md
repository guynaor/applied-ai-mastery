# My Teacher AI Learning Journal

Use this journal across seven missions and the capstone. Record only fictional, public, or safely de-identified examples. Before using any output, verify factual accuracy, standards alignment, age appropriateness, accessibility, and the teacher’s final instructional decision.

## Evidence, verification, privacy, next step

For every tab, name the artifact/source, record the check you performed, state that no student data was used, and write one next improvement.
