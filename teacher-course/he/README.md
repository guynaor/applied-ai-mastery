# יישום AI מתקדם — המסלול למורים

המסלול הדו־לשוני למורים בא׳–י״ב מלמד שימוש אחראי בבינה מלאכותית לתכנון שיעורים, מחקר, ניתוח נתונים, מצגות, תהליכי עבודה ואפליקציות פשוטות. חומרי העבודה הקנוניים באנגלית; התרגום העברי מציג את אותו מסלול למידה.

כל הדוגמאות בדיוניות. אין להזין נתוני תלמידים, פרטים משפחתיים או מידע מוגן. המורה בודק/ת דיוק, התאמה לגיל, נגישות וכל החלטה משמעותית.
