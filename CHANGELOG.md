# Changelog

All notable project changes will be documented here.

The project follows semantic-style release numbering while it is developed:

- major versions for complete course releases with substantial structural change;
- minor versions for new course volumes, sessions, or platform capabilities;
- patch versions for corrections, content refinements, and maintenance updates.
